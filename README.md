# Nova Studio

A fast, lightweight, and modern in-browser web IDE designed for touch devices, tablets, and desktop browsers. Built with instant React 18 compilation, native print/PDF engine, and standalone single-file HTML export.

🌐 **Live Demo:** [https://shadow-wave.github.io/Nova/](https://shadow-wave.github.io/Nova/)

---

## Features

- **Zero-Code Blank Canvas:** Create completely empty workspaces without unwanted boilerplate.
- **React 18 & HTML Live Compiler:** In-browser Babel compiler supporting React hooks (`useState`, `useEffect`), JSX, and modern JavaScript.
- **Native Print & Save as PDF:** Integrated print engine that connects directly to iPadOS AirPrint and Android system print dialogs.
- **Standalone HTML Export:** Export your entire project as a self-contained, offline-ready single `.html` file with a single click.
- **Touch & Mobile Optimized:** Dynamic viewport (`100dvh`), mobile navigation bar, and a quick-symbol accessory bar (`< > / { } ( ) = ; " ' => Tab`).
- **Responsive Layout:** Adaptive view modes (`Code`, `Split`, `Preview`) with fluid draggable split views for tablets and desktop screens.
- **Hardware-Accelerated Editor:** Lockstep synchronized line numbers, active line highlight, and 120Hz ProMotion-ready smooth scrolling.

## Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `Ctrl / Cmd + S` | Run & Save |
| `Ctrl / Cmd + P` | Print / Save as PDF |
| `Tab` | Indent (2 spaces) |
| `Enter` | Auto-indent matching previous line |

## Deployment (GitHub Pages)

To launch your own instance via GitHub Pages:

1. Push `index.html` to your repository's `main` branch.
2. Go to **Settings** > **Pages**.
3. Under **Build and deployment** > **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Your IDE will be live in minutes at `https://<username>.github.io/<repo>/`.
